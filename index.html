SMART ATTEND

Student Attendance System Using Face Recognition

Project Overview

A contactless, automated student attendance system powered by Artificial Intelligence and Computer Vision. Eliminates proxy attendance and saves valuable lecture time.

1. Image Capture

Captures live video frames via webcam.

2. Face Detection

Uses OpenCV and Haar Cascades.

3. Database Log

Matches faces via LBPH and logs attendance.
